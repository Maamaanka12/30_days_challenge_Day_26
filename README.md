# Day 27 — Basbaas Butter Pasta

A single-file recipe page for creamy tomato pasta with a kick of Somali **basbaas** heat. Built as part of a 30-day front-end challenge.

## What it is

A responsive, no-framework recipe page for **Dhole Recipe Co.** — "Basbaas Butter Pasta in 20 mins." Everything is in one `index.html` (HTML, CSS, and JS) — zero dependencies.

## Features

| Feature | Description |
|---|---|
| **Ingredient checklist** | Tap items to check them off; a conic progress ring fills as you gather your mise en place. |
| **Cook-along timer** | A 20-minute countdown timer with start / pause, tucked in the recipe image card. |
| **Step highlighter** | Click a step to mark it active; the step number turns from pine to tomato. |
| **Responsive layout** | Two-column grid on desktop collapses to single column on mobile. |
| **Sticky header** | Navigation + "Start cooking" button sticks to the top with a blurred backdrop. |
| **Theme** | Dark pine / sage palette with warm gold accents — restaurant-glossy feel. |

## Recipes in this dish

- **250g** rigatoni or penne (bronze-cut holds sauce best)
- **250g** cherry tomatoes, halved for charring
- **4 garlic cloves** + 1 shallot, grated and diced
- **2 tbsp** tomato paste, caramelized
- **200ml** double cream
- **40g** butter + parmesan
- **1–2 tsp** green **basbaas** (Somali chili paste) — heat to taste
- **Basil, lemon, olive oil** to finish

## Serve with

- A wedge salad or crusty bread
- Extra parmesan and lemon wedges on the side
